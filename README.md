## 🌟 Fitur Utama Portofolio Digital

1. **Dual-View Switcher:**
   * **Mode Web Interaktif:** Visualisasi modern, matriks keselarasan (*alignment check*), visualisasi 3 jaringan neurosains (CAST), filter dokumen, dan modal pratinjau PDF.
   * **Mode Format Resmi LK 2:** Tampilan lembar kerja baku sesuai format Direktorat Jenderal GTK Kemendikbudristek / LPTK, lengkap dengan lembar pengesahan tanda tangan.
2. **Cetak Dokumen Resmi (Print to PDF):** Fitur cetak yang teroptimasi `@media print` untuk menghasilkan PDF formal ukuran A4 tanpa elemen website non-esensial.
3. **Penyalin Tautan LMS Cepat:** Tombol *One-Click Copy* tautan portofolio untuk ditempelkan pada formulir penyerahan LMS.
4. **Navigasi Fluid & Responsif:** Dilengkapi navigasi pil modern, pelacak scroll otomatis (*ScrollSpy*), dan menu samping (*slide-in mobile drawer*) untuk ponsel & tablet.
5. **Mode Gelap / Terang (Dark & Light Mode).**
